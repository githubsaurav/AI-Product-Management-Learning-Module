# AI Product Management Learning Module

A self-paced curriculum on AI product management, built as interactive web modules.

## Modules

| # | Module | Status |
|---|---|---|
| 1 | [Inside an LLM: Make Better Product Decisions](modules/module-1-inside-an-llm/) — What an LLM is, and is not | Available |

### Module 1 — Inside an LLM

A 40–55 minute product-decision case for non-technical and early-career AI PMs. The learner receives a flawed brief for **ReplyRight**, a fictional support-drafting feature, investigates the LLM concepts needed to judge it across eight scenes, and repairs the brief at the end.

Covers: model vs. product, training vs. inference, tokens, token-by-token generation, context windows vs. memory, pretraining vs. post-training, hallucination and abstention, and translating these into product requirements.

**Run it:** open `modules/module-1-inside-an-llm/index.html` in a browser. No build step, no server, and no live LLM connection needed. Progress is saved in the browser's local storage.
